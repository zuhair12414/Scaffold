# packages/kt

Knowledge tracing engine. Maintains per-student, per-concept mastery estimates
using pyBKT (Bayesian Knowledge Tracing) or DKT (Deep Knowledge Tracing).

Consumes telemetry events; exposes a mastery probability for each KC that the
disclosure policy reads.
