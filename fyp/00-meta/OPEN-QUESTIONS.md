# Open questions

Move a question to `DECISIONS.md` when it is answered. Delete nothing.

## Pedagogy
- What evidence actually supports graded hints over direct answers, and how
  strong is it? Which studies, what populations, what effect sizes?
- Is there a defensible time-stuck threshold before any hint, or is it
  task-dependent?
- Does the tutor help or hurt the weakest students specifically? (This is where
  systems like this usually fail.)

## Modelling
- Per-concept model or per-task model?
- How do we get a calibrated uncertainty out of the estimator?
- Can an LLM judge understanding from code reliably enough, and how would we
  know it is wrong?

## Evaluation
- Control condition: no help, unrestricted LLM, or human TA?
- Can we run anything with real students this semester, and what does ethics
  approval require?
- What is the "solution reconstruction" test for hint leakage?

## Engineering
- Which language and lab corpus?
- Do we need to execute student code? If yes, what sandboxing?

## Scope
- Does hint level 5 exist?
- Does the instructor see anything, or is the tutor entirely student-facing?
