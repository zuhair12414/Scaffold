# Writing

## Layout
- `report/` — the FYP report
- `paper/` — any conference/journal draft (IEEE LaTeX if it goes that route)
- `slides/` — defence and progress presentations
- `figures/` — source files for diagrams, not just exports

## Discipline
- Cite as you write. Retrofitting citations is where fabricated references
  come from.
- Every pedagogical claim carries a source or is marked as our hypothesis.
- Keep the negative results in. A report that only reports what worked is
  weaker, and examiners notice.
